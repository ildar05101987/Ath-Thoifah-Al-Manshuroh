# Сайт Pondok Pesantren Ath-Thoifah Al Manshuroh (Lubuk Pakam)

- План, этапы, правила для кода: **PLAN.md** — читать первым и отмечать выполненные пункты.
- Подтверждённые факты о школе: **SCHOOL-FACTS.md** (название, адрес, программы).
- Дизайн и референсы: **design-references/README.md** (главные ориентиры: SZGMC, Zaytuna, Fora).
- `index.html` — утверждённый макет главной (тёмный изумруд + золото). Новые страницы делать в его стиле.
- 4 языка: id (основной), en, ru, ar (RTL).
- Скриншоты в `design-references/screenshots/` не коммитятся (чужие сайты, есть только локально).
- Общение с владельцем — на русском. Тексты сайта — через файлы переводов, факты о школе не выдумывать.
- Локальный просмотр: `.claude/launch.json` запускает `.claude/static-server.js` (свой сервер без зависимостей — `npx http-server` не работает в этой сети, TLS-ошибка). Открывать `index.html` напрямую как `file://` тоже можно, но тогда JS (появление блоков при скролле, смена языка) не всегда выполняется в превью-браузере — проверять только через запущенный сервер.
- Дизайн-гид: `.claude/skills/impeccable-guidance/` — текстовая адаптация скилла Impeccable (см. `SOURCE.md` там же почему не полная версия). Заглядывать в `reference/craft-floor.md` перед правками вёрстки.
- Логотип на сайте (`assets/img/logo*.svg`, favicon) перерисован по мотивам фото с ворот — оригинал слишком размыт. Заменить на официальный файл, как только школа его найдёт.
