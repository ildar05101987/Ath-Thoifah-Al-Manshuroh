# Источник

Текст в `reference/*.md` и часть `SKILL.md` — сокращённая адаптация проекта
[pbakaus/impeccable](https://github.com/pbakaus/impeccable), лицензия Apache 2.0
(файл `LICENSE` в этой папке — оригинальная лицензия проекта, скопирована без изменений).

Взято по состоянию на 28.09.2026 (коммит на тот момент — see git blame этой папки).
Из оригинала **не** включены и **не** используются:
- `skill/scripts/*` — загрузчик, который скачивает и запускает исполняемый бинарник;
- `.claude/settings.json` оригинала — хуки, автоматически вызывающие этот бинарник после каждой правки файла;
- `reference/hooks.md`, `reference/doctor.md` — документация про управление этим бинарником/хуками.

Причина: Claude Code, работающий в этом проекте, не скачивает и не исполняет
файлы из интернета — только читает и применяет текстовые рекомендации сам.

`reference/ios.md` и `reference/android.md` внутри оригинала, в свою очередь,
пересказывают guidelines Apple/Material из проекта ehmo/platform-design-skills (лицензия MIT) —
для сайта школы (веб, без нативных приложений) эти два файла практического значения не имеют.
