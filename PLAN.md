# План сайта — Pondok Pesantren Ath-Thoifah Al Manshuroh

Лубук Пакам, Deli Serdang, Sumatera Utara, Индонезия
Карта: https://maps.app.goo.gl/exViczW73zwKNhY7A

## 1. Цели сайта

1. Родители находят песантрен в Google и понимают, чему здесь учат.
2. Приём заявок на поступление (PPDB — Penerimaan Peserta Didik Baru).
3. Новости, фото, объявления для текущих родителей и выпускников.
4. Быстрый контакт через WhatsApp (в Индонезии это основной канал связи).

## 2. Стек (бесплатно, просто для любой модели)

| Что | Решение | Почему |
|---|---|---|
| Код | HTML + CSS + немного JS | Легко править, простая модель не сломает |
| Сборка 4 языков | **Eleventy (11ty)** — генератор статических сайтов | Один шаблон страницы + 4 файла переводов → 4 версии сайта. Без него пришлось бы вручную держать 28 копий страниц |
| Хостинг | **GitHub Pages** (бесплатно), сборка через GitHub Actions | Хранение и хостинг в одном месте, HTTPS из коробки |
| Резерв | Cloudflare Pages / Netlify | Тоже бесплатно, подключаются к тому же репозиторию |
| Адрес | `ИМЯ.github.io/pesantren` → позже свой домен | `.sch.id` или `.or.id` можно подключить позже |
| Форма заявки | Formspree (50 заявок/мес бесплатно) или Google Forms | Без сервера |
| Карта | Google Maps iframe | Без API-ключа |
| Время намаза | API aladhan.com (бесплатно, без ключа) | Живое расписание для Лубук Пакама |
| Шрифты | Google Fonts: Cormorant Garamond, Rubik, Amiri, Aref Ruqaa | Покрывают латиницу, кириллицу и арабский (см. `design-references/README.md`) |
| Редактирование новостей (этап 3) | Decap CMS | Админ-панель поверх GitHub, бесплатно |

## 3. Языки — 4 версии сайта

| Код | Язык | Направление | Адрес | Роль |
|---|---|---|---|---|
| `id` | Bahasa Indonesia | слева направо | `/id/` | **основной**, `/` перенаправляет сюда |
| `en` | English | слева направо | `/en/` | иностранные родители, партнёры |
| `ru` | Русский | слева направо | `/ru/` | русскоязычная аудитория |
| `ar` | العربية | **справа налево** (`dir="rtl"`) | `/ar/` | арабоязычные гости, ученые |

**Как устроено:**
- Отдельный адрес на каждый язык (а не переключение текста через JS) — так каждую версию находит Google.
- В `<head>` каждой страницы — ссылки `hreflang` на остальные 3 версии.
- Переключатель в шапке: `ID · EN · RU · عربي` — ведёт на ту же страницу в другом языке.
- Все тексты — в файлах `src/_data/i18n/id.json`, `en.json`, `ru.json`, `ar.json`. Шаблон страницы один.
- Названия песантрена, имена устазов, адрес — **не переводятся**, только транслитерируются при необходимости.

**Арабская версия (RTL):**
- `<html lang="ar" dir="rtl">`.
- В CSS использовать логические свойства: `margin-inline-start`, `padding-inline-end`, `inset-inline-start`, `text-align: start` — вместо `left/right`. Тогда RTL зеркалится сам.
- Стрелки `→` в кнопках зеркалить (`[dir=rtl] .arrow { transform: scaleX(-1) }`).
- Цифры времени намаза — оставить европейские (0–9) для читаемости.
- Шрифт заголовков — Amiri, текста — Rubik.
- Референсы: `quran-com-ar.png`, `louvre-abu-dhabi-ar.png`.

**Переводы:** черновик делает модель, но **арабский и индонезийский должен проверить носитель** (религиозная терминология: tahfidz, santri, ustadz, pengasuh). Русский и английский проверяет владелец сайта.

## 4. Структура страниц (одинаковая для всех языков)

```
/{lang}/                  Главная
/{lang}/profil/           Профиль: история, visi & misi, руководство, устазы
/{lang}/program/          Программы: Tahfidz, Diniyah, арабский, общеобразовательная школа
/{lang}/ppdb/             Поступление: условия, стоимость, документы, форма, FAQ
/{lang}/berita/           Новости и объявления
/{lang}/galeri/           Фото
/{lang}/kontak/           Карта, WhatsApp, адрес, соцсети
```

URL-адреса страниц одинаковые во всех языках (`/ru/ppdb/`, `/ar/ppdb/`) — проще переключать язык.

### Структура файлов проекта

```
src/
  _data/i18n/            id.json, en.json, ru.json, ar.json  ← все тексты
  _includes/             base.njk (шапка, подвал), секции главной
  pages/                 шаблоны страниц (один на страницу, не на язык)
  assets/css/style.css
  assets/js/main.js
  assets/img/
design-references/       референсы (на сайт не публикуются)
.github/workflows/       сборка и публикация на GitHub Pages
```

### Главная (секции — см. `index.html`)
1. Шапка: логотип, меню, кнопка «Daftar Sekarang».
2. Hero: бисмиллях, название, слоган, 2 кнопки, виджет времени намаза.
3. Цифры: santri, ustadz, лет работы, hafidz-выпускники.
4. О песантрене + Visi/Misi.
5. Программы (карточки).
6. Распорядок дня сантри (таймлайн).
7. Блок PPDB (призыв к поступлению).
8. Новости (3 последние).
9. Карта + контакты.
10. Подвал.

## 5. Дизайн-система

Подробно, со скриншотами-референсами: **`design-references/README.md`**.
**Главные ориентиры (выбор владельца):** szgmc.gov.ae (золото на тёмном, виджет намаза), zaytuna.edu (серифы, эмблема, блоки-объявления), fora.so (каркас тёмной страницы, hero с фото, уходящим в чёрный).

- **Фон:** почти чёрный изумруд `#07130f`, поверхности `#0d1f19`, `#132a22`.
- **Акцент:** золото `#d4af5a`, мягкое золото `#e9d39a`.
- **Текст:** `#ece6d6` (тёплый белый), вторичный `#a4ad9f`.
- **Узор:** восьмиконечная звезда (исламский геометрический орнамент), золото 6–8 % прозрачности.
- **Шрифты:** заголовки Cormorant Garamond (для AR — Amiri), текст Rubik (все 4 языка), декоративный арабский Aref Ruqaa.
- **Скругления:** 14–20 px; тонкие золотые рамки 1 px.
- Всё задаётся CSS-переменными в `:root` — менять цвета только там.

## 8. Правила для модели-кодера

- Из инструментов — только Eleventy. Никаких React/Vue/Tailwind.
- Цвета и шрифты — только через CSS-переменные из `:root`.
- В CSS — логические свойства (`inline-start/end`) вместо `left/right`, чтобы арабская версия работала.
- Никакого текста прямо в шаблонах — только ключи из `i18n/*.json`. Новый ключ добавлять сразу во все 4 файла.
- Каждая страница должна работать на ширине 360 px без горизонтальной прокрутки — во всех 4 языках.
- Не выдумывать факты о школе — ставить `[PLACEHOLDER]`.
- Дизайн сверять с `design-references/README.md`. Чужие тексты, фото и логотипы не копировать.
- После каждого законченного шага — коммит в git.
